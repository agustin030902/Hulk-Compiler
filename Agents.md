## Pasos a seguir para agregar un nuevo Feature al compilador

- Agregar en cada proceso de compilacion un test de prueba del nuevo feature.
- Exigir la creacion de una rama nueva para el feature nuevo, sugerir nombres al desarrollador para q el escoja.
- Reescribir el README.md general y los no generales q estan en src/codegen, src/semantic y src/bin.
- El proyecto debe ser lo mas modular posible por tanto considerar siempre separacion de codigos independientes para reutilizarlos. 
- Hacer siempre ajustes en src/bin para q la gui siempre este actualizada. 
- Mantener siempre la estructura q tenemos del proyecto.
